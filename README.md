# Smart Road Safety Awareness Website

A modern responsive Road Safety Awareness Website built using HTML and CSS.

This project spreads awareness about traffic rules, safety measures, emergency contacts, and accident prevention while helping me practice frontend web development fundamentals.

---

## Features

- Responsive Navigation Bar
- Hero Section with Background Image
- Traffic Rules Awareness Section
- Traffic Signs Cards
- Safety Measures Section
- Emergency Contact Cards
- Accident Statistics Table
- Image Gallery
- Feedback Form
- Responsive Design
- Hover Effects & Animations

---

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
